# Installer un personnage sur un nouveau serveur

## Avant de commencer

- Greycore doit être présent sur le serveur de destination.
- Le serveur doit avoir configuré son salon de validation.
- Le personnage doit déjà exister dans la bibliothèque du joueur.

## Marche à suivre

1. Aller sur le serveur où le personnage doit être installé.
2. Utiliser la commande `/mes personnages`.
3. Ouvrir le personnage concerné.
4. Ouvrir **Configuration**.
5. Cliquer sur **Installer sur ce serveur**.
6. Sélectionner la continuité souhaitée.
7. Choisir le mode d’installation.

Greycore propose alors deux modes.

### Personnage complet

Ce mode installe la continuité existante sur le nouveau serveur.

Les données suivantes sont conservées :

- le profil et l’histoire ;
- les relations ;
- les rencontres ;
- les états ;
- le téléphone et ses conversations ;
- les tenues.

Les données restent partagées entre les installations de cette même continuité. La validation et l’accès au proxy restent propres à chaque serveur.

L’avatar actuel est copié au moment de l’installation. Une modification faite ensuite depuis cette installation change uniquement l’avatar utilisé sur ce serveur.

### Nouvelle continuité

Ce mode crée une nouvelle version RP du personnage.

Sont conservés :

- le nom du proxy ;
- l’avatar global ;
- le prénom et le nom de référence.

L’avatar est copié pour le serveur de destination. Ses changements futurs n’affectent pas les autres installations.

Repartent à zéro :

- l’âge, l’organisation et l’histoire RP ;
- les relations et les rencontres ;
- les états ;
- les tenues ;
- le téléphone, qui reçoit un nouveau numéro.

## Validation

Après la création de l’installation :

1. Ajouter ou vérifier l’avatar.
2. Cliquer sur **Envoyer en validation**.
3. Attendre la décision du staff.

Le personnage et son proxy restent bloqués sur le serveur tant que l’installation n’a pas été acceptée.

En cas de refus, Greycore indique le motif et permet de corriger la fiche avant de renvoyer la demande.
